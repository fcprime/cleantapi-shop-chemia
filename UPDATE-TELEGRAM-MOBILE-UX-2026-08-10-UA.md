# Оновлення Telegram-підтвердження на телефоні

Що змінено:

- прибрано проміжне біле вікно `about:blank`;
- Telegram відкривається прямим переходом із checkout;
- перед кнопкою показано три зрозумілі кроки: `Start`, передача номера та повернення до магазину;
- під час очікування кнопка залишається активною й повторно відкриває того самого бота;
- повторне натискання не створює новий сеанс підтвердження;
- статус підтвердження, 20-хвилинний строк і блокування оформлення до перевірки залишилися без змін.

Після завантаження файлів у GitHub Netlify автоматично збере нову версію сайту. Додаткові змінні середовища або зміни в Supabase для цього оновлення не потрібні.
