# Оновлення каталогу та пошуку

Ця збірка містить зміни сортування, пошуку та добірок товарів.

## Як оновити сайт

1. Замініть файли у локальній папці репозиторію вмістом цього архіву.
2. Відкрийте Terminal у папці проєкту.
3. Виконайте:

```bash
git add .
git commit -m "Update catalog filters and product sorting"
git push
```

4. Дочекайтеся автоматичного оновлення Netlify.

## Важливо

- `npm install` повторно запускати не потрібно, якщо залежності вже встановлені.
- У Supabase нічого запускати або змінювати не потрібно.
- Товари не видаляються з бази: змінилися лише відображення, добірки та порядок карток на сайті.
