# CleanTapi Shop — запуск Telegram-підтвердження

## 1. Підготувати Telegram-групу

1. Створи приватну групу `CleanTapi Shop | Клієнти`.
2. Увімкни в ній **Теми**.
3. Додай `@cleantapishop_bot` як адміністратора.
4. Дозволь боту:
   - керувати темами;
   - надсилати повідомлення;
   - видаляти повідомлення.
5. У `@BotFather` виконай `/setprivacy` → `@cleantapishop_bot` → `Disable`.

Клієнтів у цю групу додавати не потрібно. Вони спілкуватимуться з ботом у приватному чаті.

## 2. Виконати SQL у Supabase

Відкрий `Supabase → SQL Editor`, встав увесь вміст файла:

`supabase-migration/06-telegram-order-verification.sql`

Якщо Telegram-підтвердження вже було встановлене раніше, для оновленого мобільного повернення виконай також:

`supabase-migration/07-checkout-resume.sql`

Натисни `Run`. У результаті дві колонки мають показати `true`.

## 3. Додати закриті змінні в Netlify

Відкрий `Netlify → Site configuration → Environment variables` і додай:

| Назва | Що вставити |
| --- | --- |
| `TELEGRAM_BOT_TOKEN` | новий токен `@cleantapishop_bot` від BotFather |
| `TELEGRAM_WEBHOOK_SECRET` | випадковий секрет, наприклад результат `openssl rand -hex 24` |
| `SUPABASE_SERVICE_ROLE_KEY` | секретний ключ `service_role` із Supabase |
| `SITE_URL` | повна адреса магазину без `/` у кінці, наприклад `https://example.com` |

`SUPABASE_SERVICE_ROLE_KEY` знаходиться у `Supabase → Project Settings → API Keys`. Використовуй саме секретний `service_role`, не `anon` і не `publishable`.

Ці значення нікому не надсилай і не додавай у файли GitHub.

Після додавання змінних зроби новий deploy.

## 4. Дізнатися ID менеджерської групи

1. Відкрий сайт після deploy.
2. Додай будь-який товар у кошик і натисни `Підтвердити через Telegram`.
3. Запусти бота та поділися номером. Перший запуск автоматично підключить захищений webhook.
4. У групі `CleanTapi Shop | Клієнти` напиши команду `/chatid`.
5. Бот відповість числом на кшталт `-1001234567890`.
6. Додай це число в Netlify як:

`TELEGRAM_MANAGER_CHAT_ID=-1001234567890`

Після цього ще раз зроби deploy.

## 5. Фінальний тест

1. Відкрий сайт у приватному вікні браузера.
2. Сформуй тестове замовлення.
3. Підтвердь Telegram і передай номер кнопкою бота.
4. Натисни в боті `Повернутися до магазину`.
5. Сайт сам відкриє оформлення, відновить введені дані та покаже зелений статус `Telegram підтверджено`.
5. Надішли замовлення.
6. У менеджерській групі має з’явитися окрема тема `🟢 #... — Ім’я клієнта`.
7. Напиши відповідь у цій темі — вона має одразу прийти клієнту в приватний чат із ботом.
8. Відповідь клієнта боту має з’явитися лише в його темі.

Кнопки в темі змінюють статус замовлення: `🟡 Взяти в роботу` та `✅ Завершити`. Після завершення тема закривається, але її історія залишається в групі.

## Безпека

- Підтвердження діє 20 хвилин і використовується лише для одного замовлення.
- Замовлення неможливо надіслати без реального Telegram ID і номера, переданого самим Telegram.
- Ключ `service_role`, токен бота й webhook-секрет працюють лише на сервері.
- Таблиці Telegram і замовлень закриті від публічного доступу правилами RLS.
- Старий токен бота, який раніше потрапляв у чат, потрібно відкликати через BotFather.
