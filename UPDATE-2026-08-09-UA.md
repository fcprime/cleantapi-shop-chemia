# Оновлення карток і описів — 09.08.2026

У цій збірці виправлено:

- повний опис готового набору відкривається разом зі складом;
- готовий набір можна відкрити натисканням на картку або кнопку «Детальніше»;
- на телефоні прокручується картка товару, а не сторінка позаду;
- підготовлено нові українські та російські описи для `SW15 (Mini)` і `Profi 50.1C`.

## 1. Оновити два описи в Supabase

У Supabase відкрий `SQL Editor → New query`.

Відкрий файл:

```text
supabase-migration/02-update-extractor-descriptions.sql
```

Скопіюй увесь його вміст у SQL Editor і натисни `Run`.

Цей файл змінює лише `description` і `description_ru` у товарів з ID `62` та `66`. Ціни, фото, наявність, набори й інші товари він не змінює.

Не запускай повторно `01-products-migration.sql`.

## 2. Оновити сайт

Перенеси вміст цієї збірки у чинну папку репозиторію із заміною файлів. Саму папку репозиторію не видаляй.

Потім виконай:

```bash
git add .
git commit -m "Fix product modals and update extractor descriptions"
git push
```

Після оновлення Netlify відкрий сайт на телефоні та перезавантаж сторінку. Якщо браузер показує стару версію, закрий вкладку сайту й відкрий її повторно.
