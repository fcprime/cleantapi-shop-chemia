# Оновлення повних описів товарів

Це оновлення додає окремі повні описи українською та російською мовами для 14 товарів хімії.

Короткі описи в каталозі не змінюються. Товари, яких немає в SQL-файлі, продовжують показувати свої чинні описи.

## 1. Оновіть сайт

Замініть файли проєкту файлами з цього архіву.

## 2. Завантажте код на GitHub

У Terminal, у папці проєкту, виконайте:

```bash
git add .
git commit -m "Add full product descriptions"
git push
```

## 3. Додайте описи в Supabase

1. Відкрийте Supabase.
2. Перейдіть у **SQL Editor**.
3. Створіть новий запит.
4. Скопіюйте весь вміст файла `supabase-migration/05-full-product-descriptions.sql`.
5. Натисніть **Run**.

Після виконання внизу з’явиться таблиця з 14 товарами. У двох останніх колонках для кожного рядка має бути `true`.

## Що можна редагувати надалі

У таблиці `products` з’являться поля:

- `full_description` — повний опис українською;
- `full_description_ru` — повний опис російською.

Їх можна редагувати безпосередньо в Supabase. Для абзаців використовуйте новий рядок. Заголовки `Переваги:`, `Спосіб застосування:`, `Преимущества:` та `Способ применения:` сайт оформить автоматично. Пункти списку починайте із символу `•`.

Якщо повний опис порожній, сайт автоматично показує чинний короткий опис товару.
