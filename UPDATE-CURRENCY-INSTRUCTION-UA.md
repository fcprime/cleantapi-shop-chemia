# Оновлення PLN / EUR та іконок головного екрана

1. Замініть файли репозиторію вмістом цього архіву.
2. Збережіть зміни в GitHub і дочекайтеся успішного оновлення Netlify.
3. У Supabase нічого запускати не потрібно — це оновлення не змінює каталог або базу даних.

## Що працює після оновлення

- перемикач `zł / €` у шапці сайту;
- автоматичний середній курс EUR з офіційного API NBP без API-ключа;
- оновлення курсу через серверну функцію з кешуванням;
- останній успішний курс зберігається в браузері як резервний;
- ціни перемикаються в товарах, варіантах, наборах, кошику та оформленні;
- EUR позначається як орієнтовна ціна, а базові ціни й замовлення зберігаються в PLN;
- три однакові за стилем іконки: перевірка, інформація, доставка.
