# Перенесення каталогу CleanTapi у Supabase

## Який bucket використовувати

Використовуйте тільки публічний bucket **products**. Bucket **images** старий і для нових товарів більше не потрібний. Оновлений сайт читає адреси фотографій із полів `image_url` та `images` таблиці `products`.

## Порядок дій

1. У Supabase відкрийте **Storage → products**.
2. Натисніть **Upload files** і завантажте весь вміст папки `storage-upload/products`. Імена файлів не змінюйте. Якщо Supabase запитає про заміну однакових файлів, погодьтеся.
3. Відкрийте **SQL Editor → New query**.
4. Вставте весь вміст файлу `01-products-migration.sql` і натисніть **Run**.
5. У **Table Editor → products** перевірте товар ID **71** та набори ID **1001–1004**.
6. Лише після цього опублікуйте оновлений сайт.

## Як редагувати товари надалі

- `name`, `description`, `short_desc` — український текст.
- `name_ru`, `description_ru` — російський текст.
- `price` — основна ціна.
- `variants` — фасування/колір і ціна, наприклад `[{"size":"Синя","price":140}]`.
- `in_stock` — вимкніть, щоб показати «Очікуємо постачання».
- `active` — вимкніть, щоб повністю приховати товар із сайту.
- `image_url` — головне фото картки.
- `images` — JSON-масив усіх фото галереї. Перше фото також може повторювати `image_url`.
- `category` — `chemistry`, `tools`, `accessories`, `equipment`, `window-equipment` або `sets`.
- `bundle_items` — склад готового набору. Кожен елемент має `productId`, `name`, `amount`, `qty`.
- `sort_order` — порядок показу. Менше число показується раніше.

## Як додати товар із кількома фото

1. Завантажте фото в bucket `products` з унікальними назвами, наприклад `new-product-01.jpeg`, `new-product-02.jpeg`.
2. Скопіюйте публічні URL.
3. У `image_url` вставте адресу першого фото.
4. У `images` вставте масив усіх адрес: `["URL-1","URL-2"]`.

Сумка Santoemma SW15 уже налаштована саме так: один товар, два варіанти кольору та галерея з п’яти фото.
