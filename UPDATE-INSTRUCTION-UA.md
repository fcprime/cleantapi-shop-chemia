# Оновлення каталогу CleanTapi

1. Замініть файли сайту в репозиторії вмістом цього архіву та дочекайтеся успішного оновлення Netlify.
2. У Supabase відкрийте **SQL Editor → New query**.
3. Запустіть лише файл `supabase-migration/04-catalog-navigation-and-pro-power.sql`.
4. Не запускайте повторно міграції `01`, `02` або `03`.
5. Після виконання SQL внизу мають з’явитися рядки з ID `26` і `91`, обидва зі статусом `in_stock = true`.
6. Оновіть сайт через `Cmd + Shift + R`.

SQL автоматично знаходить завантажене зображення за початком назви `pro_power_spot_remover`, тому повне ім’я файла вручну вказувати не потрібно.

`World of Clean Eco POG` включено до добірки жирних плям, але його статус наявності SQL не змінює.
